# Base de dados

Este projeto usa o **Wine Quality - Red Wine**, da UCI Machine Learning Repository.

- Fonte oficial: https://archive.ics.uci.edu/dataset/186/wine+quality
- Arquivo usado: `winequality-red.csv`
- Licença informada pela UCI: CC BY 4.0
- 1.599 observações, 11 variáveis preditoras e a variável-alvo `quality`.

Para baixar a base pelo PyCharm:

```bash
python data/download_data.py
```

O notebook também tenta fazer o download automaticamente caso o CSV não exista.
